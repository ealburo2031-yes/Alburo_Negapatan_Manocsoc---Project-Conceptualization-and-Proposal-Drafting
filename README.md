# Student Study Tracker
The Student Study Tracker is a web-based application designed to help students organize their school 
assignments, monitor deadlines, and track their academic progress. It allows users to record their 
tasks, update their status, and view summaries of their completed and pending activities. The 
application will use Python for its programming functions and JSON files to store and manage 
information.

# Problem Statement

Students often struggle to organize their school assignments, remember deadlines, and monitor their 
academic progress. Without a proper tracking system, they may overlook important tasks or have 
difficulty identifying which activities need more attention. This project aims to provide a simple and 
organized platform where students can manage their academic responsibilities and monitor their progress 
efficiently.


# Outline of Features

The application will include the following features:
Add Assignments – Allows users to enter new school tasks, including their subject, description, and deadline.
View Assignments – Displays all recorded assignments and their current status.
Update Assignments – Allows users to edit assignment details or change their completion status.
Delete Assignments – Allows users to remove tasks that are no longer needed.
Task Status Tracking – Organizes assignments into completed, pending, and overdue categories.
Progress Summary – Calculates the total number of assignments and the percentage of completed tasks.
Subject Analysis – Shows the number of assignments recorded for each subject.
Input Validation – Checks user inputs to prevent missing or invalid information.


# Description of Data to Be Collected and Stored

The application will collect and store the following information using JSON files:
Assignment ID – A unique identifier for each assignment.
Assignment Name – The title or name of the school task.
Subject – The subject where the assignment belongs.
Description – Additional details about the assignment.
Deadline – The date when the assignment should be submitted.
Status – Whether the assignment is pending or completed.
The stored information will allow the application to retrieve, update, organize, and analyze student assignments. It will also be used to generate progress summaries and statistics.
