# Student Study Tracker
The Student Study Tracker is a web-based application designed to help students organize their school 
assignments, monitor deadlines, and track their academic progress. It allows users to record their 
tasks, update their status, and view summaries of their completed and pending activities. The 
application will use Python for its programming functions and JSON files to store and manage 
information.
